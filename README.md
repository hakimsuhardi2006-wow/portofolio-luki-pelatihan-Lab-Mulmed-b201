# Website Portofolio Pribadi - Mohammad Lukman Hakim Suhardi

![Pratinjau Portofolio](gambar/foto-luki.jpg)

Selamat datang di repositori portofolio pribadiku! Proyek ini adalah website portofolio modern, bersih, dan responsif yang dirancang untuk menampilkan latar belakang, keahlian, serta pengalaman saya sebagai mahasiswa Teknik Komputer di Institut Teknologi Sepuluh Nopember (ITS).

## 🔗 Tautan Langsung (Live Demo)
Kamu bisa mengunjungi website yang sudah online di sini: 
**[https://portofolio-luki-1iv4.vercel.app/]**

## 🛠️ Teknologi yang Digunakan
Proyek ini dibangun dari nol menggunakan teknologi web dasar:
- **HTML5:** Sebagai fondasi struktur dan semantik halaman web.
- **CSS3:** Untuk tata letak (Flexbox), gaya visual, dan animasi interaktif saat disentuh (*hover*).
- **Vercel:** Platform untuk publikasi (*deployment*) web secara cepat dan andal.

## 🌟 Fitur Utama
- **UI/UX Modern:** Mengusung tema *Dark Mode* dengan aksen warna khas "Tech Blue".
- **Navigasi Lengket (Sticky Navbar):** Menu navigasi di atas yang tetap mengikuti layar saat digulir ke bawah.
- **Desain Responsif:** Tampilan yang rapi dan nyaman diakses melalui laptop, tablet, maupun perangkat seluler.
- **Bagian Khusus:**
  - `Hero:` Perkenalan singkat dan tombol aksi cepat.
  - `About:` Latar belakang pribadi beserta daftar keahlian teknis (C++, PlatformIO, Git, LTspice, dll).
  - `Projects & Experience:` Rekam jejak tugas kuliah, proyek hardware (WortelBoard), dan pengalaman kepanitiaan (GERIGI X).
  - `Contact:` Informasi kontak email dan lokasi kampus.

## 💻 Cara Menjalankan Secara Lokal
Jika kamu ingin menjalankan proyek ini di laptopmu sendiri:
1. Unduh (clone) repositori ini:
   ```bash
  git clone [https://github.com/hakimsuhardi2006/portofolio-luki.git](https://github.com/hakimsuhardi2006/portofolio-luki.git)
